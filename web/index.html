Execuções registradas
—

scripts/analisar.py é o único ponto do sistema que calcula a carteira, chama a IA e fala com o Telegram — a interface, o terminal e o Agendador de Tarefas do Windows disparam sempre o mesmo script, só com flags diferentes. Esta página lista as três formas e, onde já existe uma rota preparada, deixa o disparo a um clique.

Pela interface o mesmo botão do topo, para conferir o comando por trás
Analisar com IA Recalcula a carteira e chama o provedor de IA ativo para gerar as fichas por ativo, os riscos e os fatos. Consulta fontes na web e leva mais tempo. Exige IA configurada em Configurações. python scripts/analisar.py
Atualizar cotações Só recalcula preços e marcação a mercado, sem chamar a IA. As fichas por ativo da última leitura são mantidas (ia_reaproveitada_de), não apagadas. python scripts/analisar.py --sem-ia
Reenviar a mensagem do dia ao Telegram Envia a mensagem curta da análise já salva em disco, sem recalcular nada — só o que cruzou os limiares de Configurações. Útil depois de uma queda de conexão no envio automático. python scripts/analisar.py --enviar-ultima
Enviar o relatório completo ao Telegram O relatório inteiro, com alocação, posições e a leitura da IA, em vez da mensagem curta. É sempre notificado, e vai cortado no limite de 4096 caracteres do Telegram quando não couber. python scripts/analisar.py --enviar-ultima --completo
Testar conexão com o Telegram Confirma o token do bot e manda uma mensagem de teste ao chat configurado, sem tocar na carteira. python scripts/analisar.py --testar-telegram
Testar conexão com a IA Ping mínimo ao provedor escolhido — gasta poucos tokens e não altera a carteira nem a análise salva. python scripts/analisar.py --testar-ia --provedor <nome>
Pelo terminal na pasta do projeto, com o ambiente Python ativo
Análise completa, com relatório no terminal Mesmo cálculo do botão “Analisar com IA”, mas imprime o relatório em texto em vez de devolver JSON — é o que se roda para acompanhar ao vivo. python scripts/analisar.py
Cálculo e envio ao Telegram em um só comando A interface separa isso em dois cliques (analisar, depois reenviar); no terminal os dois saem juntos. python scripts/analisar.py --telegram
Ignorar o cache de cotações Força uma nova busca de preços mesmo que o cache ainda valha — útil para conferir uma cotação que parece desatualizada. python scripts/analisar.py --sem-cache
Rodar sem gravar no histórico Calcula e mostra o resultado sem tocar em last_analysis.json, history/ ou execucoes.json — uma execução de teste que não deve contar como leitura do dia. python scripts/analisar.py --nao-salvar
Resultado bruto em JSON O mesmo contrato que o servidor Node usa para ler o resultado: só o JSON no stdout, com o progresso no stderr. python scripts/analisar.py --json
Testar um provedor que não é o ativo O botão “Testar conexão com a IA” já cobre isso, mas pelo terminal dá para testar um provedor específico sem trocar o IA_PROVEDOR do .env. python scripts/analisar.py --testar-ia --provedor kimi
Pelo Agendador de Tarefas do Windows agendar_tarefa.ps1 — registra a rotina de segunda a sexta
Registrar a tarefa padrão Análise completa com IA, todo dia útil às 09:00, sem enviar ao Telegram. A saída fica em analise.log. .\agendar_tarefa.ps1
Outro horário, com envio ao Telegram Troca o horário e liga o envio automático do relatório ao final de cada execução agendada. .\agendar_tarefa.ps1 -Horario "18:30" -ComTelegram
Só cálculos, sem IA Agenda a versão mais barata e mais rápida da rotina — o equivalente agendado do botão “Atualizar cotações”. .\agendar_tarefa.ps1 -SemIA
Rodar a tarefa agendada agora, fora do horário Dispara a tarefa já registrada imediatamente, para testar sem esperar o próximo horário. Start-ScheduledTask -TaskName AnalisadorFinancas
Remover a tarefa Cancela o agendamento registrado — não afeta nenhuma análise já salva. .\agendar_tarefa.ps1 -Remover

Limites de alerta

O limite de concentração vale para cada posição e para os três recortes de alocação — é o traço laranja desenhado nas barras. O máximo de execuções registradas é o teto do log do Histórico: passando dele, a rodada mais antiga sai para a nova entrar.

Mensagem do Telegram o que entra no envio de cada dia

Cada bloco tem um interruptor — pode aparecer? — e um limiar — merece aparecer hoje? É o limiar que faz a mensagem variar: na maioria dos dias, a maioria dos blocos fica calada. O relatório inteiro continua no botão de envio.
